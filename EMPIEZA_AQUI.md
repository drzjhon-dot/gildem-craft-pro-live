# Gildem Craft Pro v8.6.6

**Crafting en volumen · América (West)**

1. Si tienes versiones mezcladas, usa el ZIP completo en un clon limpio del repositorio. Para actualizar desde v8.6.5 usa solo el ZIP «CAMBIOS_DESDE_8_6_5».
2. GitHub Desktop → Fetch origin/Pull antes de copiar. No hagas Merge si está en conflicto. Copia los archivos del ZIP **en la raíz** del repositorio, reemplaza y haz Commit → Push origin.
3. En Netlify verifica que el último Deploy aparece como **Published** y que el sitio declara v8.6.6.
4. Black Craft / Royal Craft → marca «Usar todo lo posible» → ajusta presupuesto, objetos y tiers → genera el plan.
5. En Resultados mira el porcentaje utilizado y la actividad semanal. Si aparece «compra por etapas», no gastes el presupuesto entero hasta confirmar el libro de materiales.
6. Historial AODP = actividad observada. **No es un recuento garantizado de ventas ni asegura un tiempo de salida.**

No incluye integración de IA web automática ni presupone que otras webs suministran feeds públicos. El motor usa West AODP y las importaciones West confirmadas manualmente.
