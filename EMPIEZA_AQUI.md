# Gildem Craft Pro v8.6.5

La actualización se entrega como código listo para GitHub, no como instalador. **Usa GitHub Desktop**, no «Upload files» de la web para subir el proyecto completo.

- Como el repositorio principal de GitHub todavía declara **v8.6.3**, utiliza `Gildem_Craft_Pro_v8_6_5_ACTUALIZACION_DESDE_8_6_3.zip` (28 archivos).
- Si realmente tienes **v8.6.4** local, puedes usar `Gildem_Craft_Pro_v8_6_5_SOLO_CAMBIOS.zip` (23 archivos).
- Si no conoces tu versión, usa el ZIP **COMPLETO** sobre una copia limpia del repositorio (conserva antes tus cambios locales).
- En GitHub Desktop: Fetch/Pull, Repository → Show in Explorer, pega los archivos descomprimidos sobre los del proyecto, Commit y Push origin. No combines versiones dentro de carpetas anidadas.
- Tras la publicación: Black Craft o Royal Craft → activa «Reservar 15%» si quieres conservar silver → genera → Resultados → abre «Primera compra orientativa».

Consulta `RELEASE_NOTES_8_6_5.md` para entender los límites y la diferencia entre objetivo de fabricación y capacidad de compra observada.
