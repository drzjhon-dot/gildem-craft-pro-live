# Empezar con Gildem Craft Pro 8.7.0

1. Extrae el ZIP de actualización sobre tu repositorio, conservando las carpetas `core/`, `tests/`, `scripts/` y `netlify/`.
2. En GitHub Desktop, confirma que no haya conflictos, haz Fetch/Pull, copia los archivos, Commit y Push origin.
3. Netlify compila `npm run build` con Node 22.
4. Prueba Black Craft y Royal Craft. Si aparecen oportunidades rentables verás Resultados normal; si no, verás «Plan de fabricación preparado» en estado **CONDICIONADO · NO FABRICAR AÚN**.
5. Los planes condicionados NO son instrucciones de compra y no declaran profit verificable.

Detalles: `RELEASE_NOTES_8_7_0.md`.
