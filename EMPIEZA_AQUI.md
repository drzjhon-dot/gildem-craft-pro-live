# Gildem Craft Pro v8.6.8 · RESULTADOS COMPACTOS

**Qué incluye:** fabricación agrupada por objeto (tier y encantamiento exactos), logística de venta debajo, lista de compras móvil sin scroll horizontal y mejor uso del presupuesto cuando existan oportunidades de volumen rentables.

**Si GitHub ya tiene v8.6.6:** usa `Gildem_Craft_Pro_v8_6_7_SOLO_CAMBIOS_DESDE_8_6_6.zip`.

1. Abre GitHub Desktop y selecciona `gildem-craft-pro-live` en `main`.
2. Guarda cambios locales si existen; primero haz Fetch origin / Pull. Si hay un Merge pendiente, **no** pegues archivos todavía.
3. Descomprime el ZIP de cambios en una carpeta temporal.
4. **Repository → Show in Explorer**, copia los archivos y carpetas **internas del ZIP** a la raíz del repositorio, reemplazando los existentes.
5. Vuelve a GitHub Desktop: Commit to main → Push origin.
6. Netlify → Deploys: comprueba `Published`. Entra a la app y verifica la etiqueta `v8.6.8`. Refresca con Ctrl+Shift+R si ves la versión vieja.
7. Crea un plan Royal o Black Craft con `Usar todo`, revisa los totales agrupados en **Resultados**, después baja a **Logística** y **Lista de compras**.

**Cuidado:** más fabricación no significa ventas garantizadas. Si hay compras por etapas o libro sin confirmar, comprueba stock y costo efectivo antes de ejecutar.
